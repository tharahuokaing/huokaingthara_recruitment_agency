# 🇰🇭 Huokaing Thara Recruitment Web Application

An interactive, responsive, and bilingual recruitment platform built for **Huokaing Thara Recruitment**. This project enables job seekers in Cambodia and internationally to browse career opportunities, filter listings by category/job type, and submit applications in both **English** and **Khmer (ភាសាខ្មែរ)**.

## ✨ Features

- **🌐 Dual Language Support (Bilingual):** Seamless instant toggling between English and Khmer (ភាសាខ្មែរ) without page reloads.
- **🔍 Smart Job Search & Filtering:** Filter job openings by category (IT, Banking, Digital Marketing, Cybersecurity, Engineering) and employment type (Full-time, Remote, Contract).
- **📝 Online Job Application Modal:** Dedicated popup form allowing candidates to apply directly for specific open roles.
- **📱 Fully Responsive Design:** Modern, clean UI optimized for desktops, tablets, and mobile devices.
- **🎨 Modern Cyber & Professional Styling:** Enhanced visual feedback, glassmorphism cards, smooth animations, and clean typography tailored for tech and enterprise recruitment.
- **📩 Contact & Inquiry Form:** Built-in inquiry form for candidates and partner organizations.

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structured for accessibility and SEO.
- **CSS3:** Custom styles, CSS variables, Flexbox, CSS Grid, animations, and responsive media queries.
- **JavaScript (ES6+):** Dynamic rendering, language switching state management, search filtering, and DOM manipulation.
- **Google Fonts:** Integration of [Kantumruy Pro](https://fonts.google.com/specimen/Kantumruy+Pro) (Khmer) and [Inter](https://fonts.google.com/specimen/Inter) (English).

## 🚀 Getting Started

### Prerequisites

No special backend or build pipeline is required to run the preview locally. Any modern web browser (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge) will work.

### Local Installation & Running

1. **Clone the Repository:**
git clone [https://github.com/your-username/huokaing-thara-recruitment.git](https://github.com/your-username/huokaing-thara-recruitment.git)
cd huokaing-thara-recruitment

2. **Open the Application:**
* Double-click `index.html` to open it directly in your browser.
* Alternatively, use the **Live Server** extension in VS Code.

## 🌐 Live Deployment (GitHub Pages)

To host this platform on GitHub Pages:

1. Go to your repository settings on GitHub (**Settings** > **Pages**).
2. Under **Source**, select the `main` (or `master`) branch.
3. Select the `/ (root)` folder and click **Save**.
4. Your site will be published at: `https://<your-username>.github.io/huokaing-thara-recruitment/`
